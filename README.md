# @tiny-build/math-cli

A beautiful, animated terminal UI built with [Ink](https://github.com/vadimdemedes/ink).

## Install

```bash
# npm
npm install -g @tiny-build/math-cli

# pnpm
pnpm add -g @tiny-build/math-cli

# jsr (deno)
deno install --global jsr:@tiny-build/math-cli
```

## Usage

```bash
math-cli
```

Press `q` to exit. Requires an interactive terminal (TTY).
